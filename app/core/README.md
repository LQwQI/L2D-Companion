# Live2D Cubism Core

这个目录需要放一个文件，但仓库里**不包含**它：

```
app/core/live2dcubismcore.min.js
```

它是 Live2D 公司的专有运行时，受 Live2D 的许可协议约束，不能随开源仓库分发。

## 怎么拿到

1. 打开 <https://www.live2d.com/sdk/cubism/>，下载 **Cubism SDK for Web**（需要同意 Live2D 的许可协议）
2. 从解压出来的 SDK 里找到 `Core/live2dcubismcore.min.js`
3. 复制到本目录，文件名保持 `live2dcubismcore.min.js`

放好之后重新启动程序即可。

> 使用 Live2D 模型时同样需要遵守模型作者的授权条款，不要把没有授权的模型一起提交到仓库里。
